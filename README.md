# teco-b2b-customer-follow-up

B2B客户的持续触达：围绕客户工作目标，设计4–5次不同主题、有新价值、容易回复的后续沟通。

Copyright (c) 2026 tecoatwork

适用于跨行业的客户开发后、询盘/报价后、样品或方案评估中的持续跟进。核心工作流是“客户状态 → 本次动机 → 新增价值 → FABM → 一个低门槛行动”。只起草，不自动发送或排期。

以下完整记录设计者提出的七组思路。统计数字和来源标签均保留，同时明确本次核查结果；保留原始主张不代表认可其真实性。

## 1. 福格行为模型：让客户产生行动

设计者的表达：让客户产生行动 = 制造动机 + 能力要求尽量低 + 触发点。

执行解释：用真实、与客户岗位相关的价值形成回复动机；降低行动难度；提供明确提示。福格模型本身强调Motivation、Ability和Prompt同时出现，B=MAP不是可计算的加法，也不是回复保证。[福格模型官方说明](https://www.behaviormodel.org/)

- 动机：这封邮件为什么与客户现在的工作有关？
- 能力：客户是否无需查数据或开会，就能在手机上完成回答？
- 提示：究竟希望客户做哪一个动作？

业务触发事件提供“为什么现在联系”的理由，CTA则明确“现在可以做什么”。不通过虚假稀缺、恐惧或内疚制造动机。

## 2. 持续4–5次跟进，不同主题

保留设计者要求：持续4–5次跟进，每次使用不同主题。

默认在已有联系之后起草4次后续跟进，第5次需要有不同的新价值。已发首封不算在后续4次内；从零开始时标明“首封+4次后续，共5封”。用户指定计数方式优先。

| 轮次 | 可选主题与新增价值 | 示例行动目标 |
| --- | --- | --- |
| 1 | 一个具体业务问题及诊断线索 | 确认该问题是否相关 |
| 2 | 一个有证据的工艺或方案差异 | 选择更相关的应用/对比项 |
| 3 | 一份真实测试、案例或可验证结果 | 是否需要查看具体证据 |
| 4 | 新市场、产品或供应链机会，或明确时机选择 | 选择当前适用的方向或联系时机 |
| 5（可选） | 尚未使用的新价值，或有帮助的收尾材料 | 接受材料、确认以后时机或结束 |

这不是必须照搬的顺序。没有案例不编案例；客户已表态则按其表态处理。无既定约定时，D+3–4、8–10、15–18、25–30天可作为规划起点，第5次可选D+35–45天；不是经研究证实的最优间隔。D0是最后一次真实联系，按采购周期、时区与节假日调整。

每次必须改变问题、证据、应用或决策支持价值，不能只是换标题催回复。若沿用现有邮件线程，保持原标题，不能为了“不同主题”强行每封另开线程。

## 3. 开发信的五类标题思路

| 类型 | 设计者思路 | 执行条件 |
| --- | --- | --- |
| 业务痛点型 Problem-based | 直击客户常见痛点，引发共鸣 | 明确问题与岗位关联；未知时用问题或条件句 |
| 市场机会型 Opportunity-based | 突出市场趋势，让客户担心错过 | 用真实机会解释时机，不人为制造FOMO |
| 预期结果型 Result-based | 用结果和数字告诉客户“能得到什么” | 数字有来源、计算口径与条件，不把预测写成保证 |
| 社会证明型 Social proof-based | 用别人认可的事实增强信任 | 真实、相关、可公开，不能虚构客户、口碑或认证 |
| 价值差异化型 Differentiation-based | 强调“别人做不到，我们能做到”的独特优势 | 用可验证比较证明；缺少竞品证据时只陈述我方已证实能力 |

每封提供一个推荐标题和一个备选，选择最适合该轮价值的类型。标题与正文必须一致，不靠姓名拼接、伪造Re:/Fwd:或暗示未发生的见面来获取注意。

## 5. 正文：1秒破冰 + 1格对冲 + 1个钩子

### （1）黄金开头 Hook：1秒破冰

设计者要求：拒绝任何形式的模板客套，如Hope you are well；用冷静、专业的商业口吻进入。

路径一是直切对方岗位KPI相关的问题；路径二是顺理成章说明联系渊源，例如查得的海关需求线索或竞争对手动作。执行中只有真正获取、核实且适合使用的信息才能写入，不假称拥有海关数据或知道竞争对手内部动作。专业不等于冒犯，克制不等于机械。

### （2）价值对冲 Body：1格对冲

设计者要求：去掉自嗨式大篇幅工厂介绍，把生产能力翻译成客户受益的方案。使用FABM叙事：

- Feature / Advantage：亮出真实硬实力参数或能力，解释其相对优势。
- Benefit：对应客户公司的具体收益或要解决的麻烦。
- Meaning：解释该结果对联系人完成工作、推动内部决策或赢得市场机会的意义。

每封只保留一条价值主线。没有测量依据时不编造收益数字；Meaning是根据角色与实际沟通提出的假设。虽然结构叫FABM，所有事实仍需Proof支持，不能省略证据核验。

### （3）行动力学 CTA：1个钩子

设计者要求：不把球踢给客户，不用Waiting for your reply等含糊收尾。设计决策门槛极低的封闭式提问，让客户用一个数字、A/B或Yes/No就能回复。

例如，材料确实存在且可分享时：“Would the test summary be useful?”应用尚不明确时：“Is this mainly for A) retail or B) professional use?”实际选项要匹配产品和客户。

默认一个CTA，不把应用、预算、数量、会议时间同时抛给客户。不为套用封闭式而问无意义问题；客户已确认兴趣并进入评估时，使用真正需要的具体下一步。

## 有来源的替代优化方法

更新核查：2026-10-17。以下是替代策略，不是对B2/B3/B4/B6/B7原数字的补证。原主张保留在上表作为审查记录；执行优先采用本节。来源为平台观察性研究，支持提出测试方向，不能保证因果或本客户转化。

### 证据来源与边界

- **S1 — Gong个性化研究**：[原文](https://www.gong.io/blog/4-data-backed-ways-to-increase-your-email-reply-rate-and-book-that-meeting)，2023-07-07发布、2026-03-04更新。分析超过250家公司、30,000封开发邮件；报告不同职位层级对个性化类型的回复表现不同，公司话题对Director及以上更相关。未验证“第一句近期动态提升2.1倍”，也没有测量Meaning带来的阅读秒数。未给出随机分组因果设计。
- **S2 — Gong与30MPC冷邮件指南**：[官方PDF，第10页CTA](https://www.gong.io/files/gong-guide-how-to-master-cold-email-get-the-data-backed-guide-based-on-85-million-emails.pdf#page=10)。全指南基于85M+冷邮件，建议用兴趣提问或有用的具体offer替代直接索取会议；举例包括报告和审查。公开图表未充分披露CTA子样本、控制变量及基线计算细节，因此采用方向，不搬用提升数字。不是对“1–2个专业问题+114%”或“视觉附件+36%”的验证；冷邮件结论不强套已进入交易的客户。
- **S3 — Woodpecker逐轮基准**：[官方平台数据](https://woodpecker.co/cold-email-benchmarks/)，页面更新2026-08-05，数据标签为“last 90 days, 2025”，确切日期区间未明确。4–6封序列涉及1,020家公司：首封回复中位数1.0%，第4封0.5%；第5、6封各0.3%，但对应公司分别只有436、166家。各轮送达分母与留下的人群不同，不能相加成总回复率，也不能解释为同一个人的回复概率。支持关注后续轮次的边际产出，不证明第3–4天最优或总回复提高48%。

### 小规模验证方式

一次只测一个变化：E2事件关联开头对比应用开头；E3/E4有用材料的兴趣CTA对比现行CTA；E7角色适配对比通用价值表达。保留同一阶段、名单条件和观察窗，按公司分组，报告实际人数及分母。材料必须两版都真实可用，不同时更改标题、长度和发送节奏。E6评估逐轮增量；序列累计有效回复率按“至少一次有效回复的独立联系人 ÷ 至少收到一次邮件的独立联系人”计算，不能累加每轮百分比。退订或拒绝即时停止，不为测试继续触达。

每个触发都回答：为什么与这个客户有关、带来什么新价值、有什么证据、希望客户完成哪一个小动作。事实、推测与待准备材料分开。

## 统计使用规则

第4、6节是15条原始主张的审查台账，不是已证实的转化指南。每次想引用精确数字，必须核查原始出处、样本、年份、冷/暖触达场景、指标分母、基线、相对提升与百分点。平台观察性相关不自动等于因果，不同渠道/国家/阶段不能直接套用。

本次对所称发布机构与关键数值进行了限定检索。T1–T8、B2–B4、B6–B7未定位到匹配原始研究；未穷尽付费或未公开资料。B1找到原始研究但需纠正来源和适用人群；B5有方向性支持但数值与出处不匹配。

- [Boomerang 2016原始分析](https://blog.boomerangapp.com/2016/02/7-tips-for-getting-more-responses-to-your-emails-with-data/)：邮件长度研究，样本不是专门的B2B冷邮件。
- [HubSpot邮件长度文章](https://blog.hubspot.com/sales/ideal-length-sales-email)：对Boomerang来源的追溯，不是本项目所称2025报告的验证。
- [Gong销售邮件分析](https://www.gong.io/blog/how-to-write-a-sales-email)：区分冷触达的兴趣CTA和交易阶段的具体CTA。
- [Mailchimp MPP说明](https://mailchimp.com/help/apple-privacy-faq/)：Apple Mail预加载会使打开统计失真。因此不把打开率或推断阅读时长作为唯一优化依据。

A/B测试每次只改变一个变量，例如痛点标题对比机会标题；名单按公司分组，观察窗与其他条件保持一致。主要看独立联系人的有效回复率、正向回复率、下一步接受率及退订/投诉。报告实际人数和分母，排除自动回复；小样本仅作探索。此Skill不自动运行测试或发送邮件。

## 回复后的处理

- 客户回复：停下剩余序列，先回应具体内容。
- 客户要求稍后：按约定日期联系，不继续按旧节奏追发。
- 拒绝、退订、停止请求：停止该营销跟进，不转渠道绕过。
- 休假自动回复：按返岗时间调整；不算有效回复。
- 退信、离职：暂停旧地址，核对合适的公开职业联系路径。
- 4–5次仍无回应：结束当前序列，未来有真实新价值时再评估，不无限循环。

```text
使用 $teco-b2b-customer-follow-up，结合已准备的信息库和下面的沟通记录，为这个客户设计4次不同主题的后续跟进。

请先判断客户当前阶段与联系人的Meaning，再给出每轮新增价值、建议时点、证据依据、推荐及备选标题、可复制的邮件正文和一个低门槛CTA。英文正文以50–125词为目标。没有证据的内容不编造，缺少的材料单独列出；只起草，不发送。

客户公司、网站与联系人：[填写或引用已有资料]
```
